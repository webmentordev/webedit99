GLOBAL RULES
ids are uuid (v7 preferred)
created_at & updated_at in all tables
deleted_at (soft delete) on: products, customers, coupons, brands, collections, pages
All is_featured must be boolean, default false
All is_active must be boolean, default true
All sort_order must be integer, default 1
Money = integer in minor units (e.g. cents), never float
Table names are plural
Every foreign key is indexed
Every store-owned table has store_id, and slugs/codes are unique per store
media_files is the single table for all files. Nullable relations = a file not tied to any record
A product can be in multiple collections or sub-collections (via product_collections)
values in [] are enums
